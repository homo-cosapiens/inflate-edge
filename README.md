# ふくらめ、ギリギリ（初版）

## 起動
`index.html` と `game.js` を同じフォルダに保存し、`index.html` をブラウザで開いてください。インターネット接続やインストールは不要です。

## 遊び方
「開始 / リトライ」を押してラウンド開始。Spaceキー、またはCanvas上でマウス／タッチを長押しすると球が膨らみます。離すと縮み、縮小完了時に段階に応じて10・35・100点が確定します。赤い刃の軌道予告を見てタイミングを調整してください。ラウンドは60秒、ライフは3つです。ライフがなくなるか時間切れで終了し、ボタンから再挑戦できます。

キー／ポインターのキャンセル、ウィンドウのフォーカス喪失、タブ非表示では保留点を破棄します。非表示中はゲーム時間も進みません。

## 検証状況
GitHubへの保存と読み戻し、およびコードレビューを実施しました。レビューでは、刃の衝突フラグを実命中時だけ設定する修正と、縮小完了後に得点を確定する修正を確認しています。**実ブラウザでの試遊と自動テストは未実施**です。

## 初版の範囲
音、ベストスコア保存、派手な演出は未実装です。表示は自作のCanvas図形のみで、第三者素材・外部ライブラリ・外部通信は使用しません。
